# Getting started programming the XRP robot

The XRP robot is a basic, single-board-computer (SBC) based robot that's capable of doing everything from simple programming to complex programming using the FIRST robotics environment known as WPILib.

## Build and connect

You will need:

- [ ] The XRP robot box, with robot inside
- [ ] USB-A to USB-C data cable (we have red ones in the sorter)
- [ ] A laptop with 
    - [ ] Chrome or Firefox (Chrome is recommended for best results)
    - [ ] FRC VSCode (optional, for WPILib)
    - [ ] git source control system (ask a mentor for help)

Visit [the XRP Experience site](https://xrp.experiential.bot) for videos and documentation links; this is your hub for help!

1. Check to make sure the XRP bot power switch is OFF
2. Make sure your laptop is powered on and connectedd to the Internet
3. Connect your laptop to the XRP bot via the USB-C connector on the bot; it should power on and lights should light
4. Open [the XRP Code Editor website](https://xrpcode.wpi.edu/), 
    - read any notices that appear, and dismiss them
    - choose your programming experience; this guide assumes Micropython
    - Click `Connext XRP`, then `USB Connection`, and select `Board in FS Mode` or similar for the device
    - **Update** if you are prompted to update the XRP, follow the instructions to do that.
5. Go to [the introduction course](https://introtoroboticsv2.readthedocs.io/en/latest/course/course_info/index.html) and work your way through it! There are also videos on the Experience site if you learn better that way.
